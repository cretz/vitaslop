Where the import's time goes

Pick what you would import: a .pkg AND its work.bin, or a dumped folder. Nothing is kept and nothing leaves the device except the result text, and only when this page is served by the dev server. "Measure the parts" times reading, crypto and storage on their own, about a minute. "Run the real import" runs the actual import twice, old read path against new, stopping after 128 MB each, about a minute and a half.
