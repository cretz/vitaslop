vitaslop H.264 conformance - browser decoder

The same suite cargo test -p vitaslop-h264 runs, executed here against the browser's own WebCodecs VideoDecoder - the one backend a native test cannot reach. The stream is synthesised from I_PCM macroblocks, so the correct pixels are knowable from the bitstream itself: no reference decoder, no checked-in sample file, and byte equality is a legitimate assertion.

A browser with no VideoDecoder reports that and passes. That is a real configuration, not a defect.
