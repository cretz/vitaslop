# vitaslop projects

This directory is the Cargo workspace where all `vitaslop-*` projects live.

- [vitaslop-conformance-harness](vitaslop-conformance-harness/) - The only crate that runs the conformance corpora against vitaslop (a dev-only test runner). Supplies the engine and the corpus's host ABI (Linux-EABI for arm); exercises the emitted WASM path via wasmtime.
- [vitaslop-conformance-suite-arm](vitaslop-conformance-suite-arm/) - Generic ARM conformance corpus: hand-written `asm` plus seed state per case, with the assembled `[bin]` and expected `[out]` regenerated by the `regen` bin from an `as`/`qemu` oracle. No vitaslop dependency; see its README.
- [vitaslop-conformance-suite-vita](vitaslop-conformance-suite-vita/) - Generic Vita conformance corpus. Placeholder (shape, generator, and oracle TBD).
- [vitaslop-desktop](vitaslop-desktop/) - Native binary running the same wasm and wgpu stack on the desktop.
- [vitaslop-loader](vitaslop-loader/) - Parses SELF/ELF, relocations, and NID tables, and does provenance-based entry-point enumeration to feed the transpiler.
- [vitaslop-native](vitaslop-native/) - OS-level mechanisms shared by every non-browser host (desktop and, someday, mobile): the wasmtime-backed engine that runs the transpiler's WASM, and later the mmap image source and worker threads. Never built for wasm32.
- [vitaslop-platform](vitaslop-platform/) - Web/native abstraction seam: random-access asset storage (OPFS vs mmap), window, renderer, input, audio.
- [vitaslop-runtime](vitaslop-runtime/) - Engine-agnostic core (compiles to wasm32): guest memory, dispatch map, scheduler, the transpiler-to-runtime ABI logic, and the ROM-to-wasm-blob transform. Holds no wasm engine; the host supplies it (vitaslop-native or the browser).
- [vitaslop-transpiler](vitaslop-transpiler/) - Vita-agnostic ARMv7 plus Thumb-2 plus NEON plus VFP to WASM engine. Decodes via our yaxpeax-arm consolidation fork, lifts to an IR, emits WASM.
- [vitaslop-web](vitaslop-web/) - Browser app: a Rust `cdylib` (wasm-bindgen) plus a vite/TypeScript static page.
